# OmniCribra

A Windows app that searches the sites you choose (DBA, GulogGratis, Facebook Marketplace and web shops) at once and gives you one list of deals with price, place and link. It can watch searches and single ads for you and tell you when something new or cheaper shows up.

**Download:** [Releases](https://github.com/tjeerocka/omnicribra/releases/latest) → `OmniCribra-Setup.exe`.
The app updates itself after that.

This repository only holds the signed installers. The app checks the signature before it installs an update.
